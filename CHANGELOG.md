## 🔄 Convention de Versioning

Nous utilisons [Semantic Versioning](https://semver.org/lang/fr/) :

- **MAJOR** : Changements incompatibles avec l'API précédente
- **MINOR** : Ajout de fonctionnalités rétrocompatibles
- **PATCH** : Corrections de bugs rétrocompatibles

Exemple: `1.2.3` = Major 1, Minor 2, Patch 3

## 📝 Format des Entrées

Chaque version doit contenir ces sections :

### Ajouté

Nouvelles fonctionnalités ajoutées.

### Modifié

Changements existants modifiés.

### Déprécié

Fonctionnalités soon-to-be removed.

### Supprimé

Fonctionnalités removed.

### Corrigé

Tous les correctifs de bugs.

### Sécurité

Tout ce qui touche à la sécurité.
